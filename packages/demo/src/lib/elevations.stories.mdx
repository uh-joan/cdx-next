# Elevations

> [The Elevation system] emits CSS classes for applying elevation. These classes
> follow the pattern `mat-elevation-z#`, where `#` is the elevation number you
> want, from 0 to 24. These predefined classes use the CSS `box-shadow` settings
> defined by the Material Design specification.

<div className="mat-typography">
  {[...Array(25).keys()].map((level) => (
    <div
      style={{ height: 75, width: '75%', textAlign: 'center', margin: 25 }}
      className={`mat-elevation-z${level} mat-headline`}
    >
      {level}
    </div>
  ))}
</div>
