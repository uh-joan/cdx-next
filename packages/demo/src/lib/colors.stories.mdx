# Colors

## Palette

> A **palette** is a collection of colors representing a portion of color space.
> Each value in this collection is called a **hue**. In Material Design, each
> hues in a palette has an identifier number. These identifier numbers include
> 50, and then each 100 value between 100 and 900. The numbers order hues within
> a palette from lightest to darkest.

By default, Angular Material associates the tokens `lighter`, `default`, and
`darker` to the hue values 100, 500, and 700, respectively. These are the colors
that designers would use during "average" component design. They are called out
below.

<div>
  {['primary', 'accent', 'warn'].map((n) => (
    <>
      <h3 style={{ textTransform: 'capitalize' }}>{n}</h3>
      <div className={`${n}-palette`}>
        {[
          { hue: 50 },
          { hue: 100, name: 'lighter' },
          { hue: 200 },
          { hue: 300 },
          { hue: 400 },
          { hue: 500, name: 'default' },
          { hue: 600 },
          { hue: 700, name: 'darker' },
          { hue: 800 },
          { hue: 900 },
        ].map(({ hue, name }) => (
          <div className={'bg-' + hue}>
            <span className="mat-typography">
              <div className="mat-title">{hue}</div>
              {name && <div className="mat-caption">{name}</div>}
            </span>
          </div>
        ))}
      </div>
    </>
  ))}
</div>
