# Typography

## Levels

> A **typography** level is a collection of typographic styles that corresponds
> to a specific part of an application's structure, such as a header. Each level
> includes styles for font family, font weight, font size, and letter spacing.
> Angular Material uses the typography levels from the
> [2014 version of the Material Design specification](https://material.io/archive/guidelines/style/typography.html#typography-styles).

Border and background color are used in the following examples to demonstrate
that many of the typography levels _also_ adjust spacing by way of margins.

<dl className="mat-typography">
  {[
    'display-4',
    'display-3',
    'display-2',
    'display-1',
    'headline',
    'title',
    'subheading-2',
    'subheading-1',
    'body-1',
    'body-2',
    'caption',
  ].map((level, index) => (
    <React.Fragment key={index}>
      <dt>{level}</dt>
      <dd
        style={{ border: '1px dashed', padding: '0', backgroundColor: '#ddd' }}
      >
        <div>
          <div className={`mat-${level}`} style={{ backgroundColor: 'white' }}>
            The quick brown fox jumps over the lazy dog
          </div>
        </div>
      </dd>
    </React.Fragment>
  ))}
</dl>
