The Helix snackbar component is built using selected styles from the Angular Material snackbar framework. For implementation details, see the Code tab.

Options

  • A snackbar can include a single action.
  • “Dismiss” or “Cancel” actions are optional.
  • Without actions, snackbars will disappear automatically.

Snackbars vs. dialogs

Dialogs are intended for displaying important messages. Choose the appropriate component based on message priority to prevent overusing snackbars.

  • Use snackbars for low priority and when user action is optional.
  • Use dialogs for high priority messages that require user action.

Usage

Text labels give clear, concise updates on completed processes and should fit on one line whenever possible. Don't use icons, stylized text, or inline links in snackbars, as they add unnecessary complexity. If a link is needed, use a button or a different component.
