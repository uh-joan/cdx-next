The Helix checkbox component is built using selected styles from the Angular Material checkbox framework. For implementation details, see the Code tab.

  • The label should be scannable.
  • Selected items are more prominent than unselected items.
  • Checkboxes can have parent-child relationships.
  • Use a parent checkbox to make it more efficient to select many items.

Usage

Use checkboxes to let users select one or more options, and include a parent checkbox to allow selecting or deselecting all items at once. Don't use checkboxes when only one option can be selected — use radio buttons instead.
