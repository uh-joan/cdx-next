The Helix progress bar component is built using selected styles from the Angular Material progress bar framework. For implementation details, see the Code tab.

Options

Choose from these two types of progress bars:

Determinate

  • Operations where the percentage of the operation complete is known should use the determinate indicator.
  • Determinate progress bars fill from 0 to 100%.

Indeterminate

  • Operations where the user is asked to wait while something finishes and it’s not necessary to indicate how long it will take should use the indeterminate indicator.
  • Indeterminate progress bars animate continuously along a fixed track to indicate ongoing activity until the process finishes.

Usage

Use progress bar when the process can be described with quantitative information, such as a percentage. Don't use progress bar when longer load times are expected and additional content will be revealed, use skeleton states instead.
