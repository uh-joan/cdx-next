The Helix dialog component is built using selected styles from the Angular Material dialog framework. For implementation details, see the Code tab.

Options

Use dialogs to prompt users to act on important information. They should focus on a single task, while optionally showing supporting details. Dialogs are commonly used to confirm high-risk actions, such as deleting progress.

Usage

  • Convey a clear, concise statement or question.
  • Be direct and unambiguous; avoid apologetic (“Sorry for the interruption”), alarming (“Warning!”), or vague (“Are you sure?”) language.
  • Allow users to confirm, dismiss, or acknowledge an action.
  • Provide only one action if it’s an acknowledgement.
  • Provide two actions if one confirms and the other dismisses.
  • Use clear, descriptive labels that reflect the action (e.g., avoid generic “Yes” / “No”).
