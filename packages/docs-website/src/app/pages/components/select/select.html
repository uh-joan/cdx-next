The Helix select component is built using selected styles from the Angular Material select framework. For implementation details, see the Code tab.

Options

Styles

Both types of select components use a container to offer a visual cue for interaction and deliver the same functionality.

  • Outlined – Less visual emphasis, helps to simplify the layout.
  • Filled – More distinct from other components (like buttons) and surrounding content.

Density

Selects are available in five size options, controlled by the density setting.

  • Density 0 is the default
  • Density -4 aligns with the default button height of 40px
  • Use alternative densities to create a clear visual hierarchy—sparingly and with purpose.

For more detail, see .

Icons

Icons help clarify meaning, but should never be purely decorative.

  • Use a leading icon to reinforce the select’s intent.

For guidance on choosing and applying icons, see .

States

Outlined and filled selects have enabled, hovered, focused, disabled and error states.

Usage

Do group and order options logically. Group them by category and sort them alphabetically when useful. Don’t overload the Select with too many options or truncate options excessively. Do use a clear, short and persistent label. Don’t use a Select for actions (e.g., Delete, Send, Submit). Selects are for choosing values.
