The Helix slide toggle component is built using selected styles from the Angular Material slide toggle framework. For implementation details, see the Code tab.

  • Ensure the switch’s position (on or off) is easily visible at a glance.

Options

Density

The slide toggle is available in three size options, controlled by the density setting.

  • Density 0 is the default.
  • Use alternative densities to create a clear visual hierarchy—sparingly and with purpose.

For more detail, see .

Usage

Keep labels short and clear. Describe the action that occurs when the slide toggle is on. Don’t use slide toggles for multiple selections or actions that need saving. Changes should apply instantly. Use checkboxes instead.
