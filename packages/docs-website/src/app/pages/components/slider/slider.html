The Helix slider component is built using selected styles from the Angular Material slider framework. For implementation details, see the Code tab.

Options

There are two types of sliders: basic and range.

The track represents the full range of selectable values on a slider and is divided into active and inactive sections.

  • The active track runs from the minimum value to the handle, or between the two handles on a range slider.
  • The inactive track extends from the handle to the maximum value, or outside the handles on a range slider.

Values increase from left to right (reversed in right-to-left languages).

  • A value is displayed when a user interacts with a handle.
  • Range sliders show only one value at a time.
  • If the value is displayed elsewhere, the indicator is not required.
