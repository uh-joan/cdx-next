The Helix icon component is built using selected styles from the Angular Material icon framework. For implementation details, see the Code tab.

Icons are visual symbols that communicate information, afford interactivity and draw attention to important information at a glance. They are simple, familiar and universal.

Options

Styles

Icons use specific color themes to convey their importance or meaning.

Helix uses the Google Material Symbols and Icons library, configured to align with the Clarivate brand guidelines and maintain consistency across the system.

Choose from three functional color themes:

  • Standard – Default style for most icons.
  • Semantic – Use to reinforce meaning, only on the corresponding surface color.
  • Distinct – Use sparingly for emphasis or decorative purposes.

Which icons to use

Almost every icon in the Helix Figma library is a standard Material icon. Use those through the Material Symbols font, by name: <mat-icon>search</mat-icon>.

The few icons Clarivate draws itself, such as the AI and brand icons, and the pictograms come from @hlx/helix-icons. Add provideHelixIcons() to your app config and use them with the hlx and hlx-pictogram namespaces: <mat-icon svgIcon="hlx:ai-summary"></mat-icon>.

Setup in your app

Wire icons once at the app level. Load a single Material Symbols family (Outlined, the Helix settings) and register the custom icons through provideHelixIcons() — don't scatter MatIconRegistry.addSvgIcon calls across components.

Do

  • Load one Material Symbols family (Outlined) once, in index.html.
  • Register custom, AI and pictogram icons once with provideHelixIcons().
  • Reference Material icons by name; custom ones via the hlx: / hlx-pictogram: namespaces.

Don't

  • Load several Material icon families (Filled, Rounded, Sharp…) when you use one.
  • Ship a bespoke icon font — use the shared Helix set.
  • Register the same SVGs in multiple places; do it once at app config.
