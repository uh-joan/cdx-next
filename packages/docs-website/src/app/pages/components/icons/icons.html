Which icons to use

Almost every icon in the Helix Figma library is a standard Material icon. Use those through the Material Symbols font, by name: <mat-icon>search</mat-icon>.

The few icons Clarivate draws itself, such as the AI and brand icons, come from @cdx/helix-icons. Add provideHelixIcons() to your app config and use them with the hlx namespace: <mat-icon svgIcon="hlx:ai-summary"></mat-icon>.
