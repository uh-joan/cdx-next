The Helix input component is built using selected styles from the Angular Material input framework. For implementation details, see the Code tab.

Options

Styles

Both types of input fields use a container to offer a visual cue for interaction and deliver the same functionality.

  • Outlined – Less visual emphasis, helps to simplify the layout.
  • Filled – More distinct from other components (like buttons) and surrounding content.

Text areas are taller than standard inputs and wrap overflow text onto new lines. The large size suggests longer responses. See .

States

The input component has integrated hover, focus and error states.

Density

Input fields are available in five size options, controlled by the density setting.

  • Density 0 is the default.
  • Density -4 aligns with the default button height of 40px.
  • Use alternative densities to create a clear visual hierarchy—sparingly and with purpose.

For more detail, see .

Icons

Icons help clarify meaning, but should never be purely decorative.

  • Use a leading icon to reinforce the input’s intent.
  • Use a trailing icon to suggest interactivity, such as clearing the input.

For guidance on choosing and applying icons, see .

Usage

When using both types of inputs in a UI, separate them by region (e.g. page header and modal). Don't use both types next to each other or within the same form. Keep the label text short, clear, and fully visible. Don't use labels that are too long, wrap onto multiple lines, or get truncated.
