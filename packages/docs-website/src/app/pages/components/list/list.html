The Helix list component is built using selected styles from the Angular Material list framework. For implementation details, see the Code tab.

Options

Lists are vertical groups of text, icons, images, or other elements designed for easy scanning. Items can include multiple actions, such as selection, buttons, or menus.

Usage

Don’t scale components without adjusting related elements, like text, as this can create line lengths that are hard to read.
