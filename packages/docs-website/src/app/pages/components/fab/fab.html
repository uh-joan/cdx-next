The Helix FAB component is built using selected styles from the Angular Material button framework. For implementation details, see the Code tab.

Options

Color and size

FABs have four color themes and two sizes to signal the importance of an action.

Choose from four functional color themes:

  • Primary – Our default. Use for most actions.
  • Invert – Use on dark backgrounds for contrast.
  • Accent – Use sparingly for actions that need extra emphasis.
  • AI – Use for actions that trigger AI-powered tasks.

Usage

Use clear and simple icons such as add, message, or edit. Don't display multiple FABs on one screen and steer clear of confusing or vague icons for less common actions.

Use matFab for the default size, matMiniFab for the small size and matFab extended for a FAB with a label. Apply a color with a class on the FAB or on a parent: hlx-btn-accent, hlx-btn-ai (AI gradient) or hlx-btn-invert (Primary needs no class).
