The Helix tooltip component is built using selected styles from the Angular Material tooltip framework. For implementation details, see the Code tab.

Options

Use tooltips to add additional context to a button or other UI element. There are two types of tooltips: plain and rich.

  • Plain tooltips briefly describe a UI element or action. They are commonly used to label icon-only buttons or fields without visible text.
  • Rich tooltips provide more detailed information, such as explaining the value or behavior of a feature. They can include an optional title, links, and buttons.

Usage

Use plain tooltips to label icon buttons and provide brief descriptions of the UI elements. Don't use plain tooltips for lengthy explanations. Use rich tooltips when additional details or actions are needed for a UI element or new feature. Don’t hide critical information in tooltips, as they’re easy to miss. Use an interruptive dialog instead.

Rich tooltip

Rich tooltips use the hlxTooltip directive (RichTooltipDirective) from @cdx/ngx-branding, not Angular Material. Pass an ng-template with the content and set tooltipTrigger to 'hover' (default) or 'click'.
