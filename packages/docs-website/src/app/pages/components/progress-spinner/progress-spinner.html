The Helix progress spinner is built using selected styles from the Angular Material framework. For implementation details, see the Code tab.

Options

The progress-spinner supports mainly this mode:

  • Indeterminate – Indicates that something is happening without conveying a discrete progress.

Usage

Can appear within components, buttons, or sections when only a specific part of the UI is loading. Don't use Progress Spinner for processes with known or measurable duration—use a Progress Bar instead.
