The Helix menu component is built using selected styles from the Angular Material menu framework. For implementation details, see the Code tab.

Options

Use menus in situations that need extra actions, like:

  • Overflow menus
  • Text field dropdown menus
  • Select menus
  • Context menus

Icons

Icons help clarify meaning, but should never be purely decorative.

  • Use a leading icon to reinforce the label’s intent.
  • Use a trailing icon to suggest interactivity, such as a dropdown or navigation.

For guidance on choosing and applying icons, see .

Usage

Submenus should open beside their parent menu item without overlapping it.
