Color and types

Hyperlinks combine color themes and types to signal the importance of the hyperlink and make it work with its surroundings.

Choose from three colors:

  • Primary – Our default. Use for most hyperlinks.
  • Blue – Use for hyperlinks that need extra emphasis or differentiation.
  • Visited – Only use when a hyperlink has been clicked (visited).

There are two types of underline:

  • On hover – Use for standalone hyperlinks.
  • Permanent – Use for inline hyperlinks to ensure accessibility.

Buttons vs. links

Use buttons and links purposefully to support clarity and accessibility.

  • Use a button for actions that affect the current page—such as submitting a form, starting media playback, or closing a modal.
  • Use a link to navigate to a new page or to a different section within the current page (anchor navigation).

Avoid substituting one for the other. Buttons and links behave differently in browsers and are interpreted differently by assistive technologies. Using the correct element ensures a more inclusive experience for all users. See also .

Usage

Use semibold weight and permanent underline to style inline hyperlinks. Don’t rely on color alone to indicate inline links, and avoid using links for actions—use buttons instead.

The Helix theme styles every <a> element: links inherit the surrounding text color and are underlined on hover. Add the underline attribute for a permanent underline on inline links.
