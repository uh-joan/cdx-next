The Helix tabs component is built using selected styles from the Angular Material tabs framework. For implementation details, see the Code tab.

Options

The active indicator (bar) can either fit the content or the width of the tab.

  • Tabs enable users to navigate between groups of related content efficiently.
  • Content within a set of tabs should share a common organizing principle, but each tab presents distinct content.
  • Only one tab can be active at a time.
  • Tabs are considered peers and exist at the same hierarchical level within the navigation structure.
  • Tabs can scroll horizontally to accommodate overflow.

Usage

Use short labels and categorize related groups into defined sets. Don’t use tabs for content that must be read in order. Use typographic hierarchy and spacing instead. Don’t mix tabs with icons and text labels alongside tabs that use text labels only.
