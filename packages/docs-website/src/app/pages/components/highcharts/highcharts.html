Installation

Usage

Use Highcharts.setOptions to apply the HLX theme globally. The same options can be referenced later with Highcharts.getOptions(). Although its usage is optional, Highcharts does provide an official wrapper for Angular that helps with container management among other features. For extensive information on Highcharts options and functions, visit the official Highcharts API pages.

Accessibility

Always include the , unless there is an explicit reason not to do so. Including this module will make your charts compatible with assistive technologies used by people with disabilities, and also improve the usability of your charts, helping you reach a broader audience.

To include the module, import and initialize it on the core Highcharts library. Other modules should be initalized before the Accessibility module.

Styled Mode

For styledMode to work you need to import the default style sheet . For HLX colors you also need to import theme-highcharts.scss.

With styledMode enabled you have full control over CSS overrides. There's just one caveat: After enabling styled mode you can no longer style with chart options. Some rare cases require styledMode. E.g. increasing the chart colorCount above the limit of 10 can only be done with styledMode disabled.
