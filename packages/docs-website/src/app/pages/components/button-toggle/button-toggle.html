The Helix button toggle component is built using selected styles from the Angular Material button toggle framework. For implementation details, see the Code tab.

Options

Color and types

Button toggles combine color themes and types to signal the importance of an action.

Choose between two themes:

  • Light – Our default. Use for most scenarios.
  • Dark – Use sparingly for navigation that needs extra emphasis.

There are three button types to help communicate priority:

  • Equal button width – Use as the default for a balanced UI.
  • Variable button width – Can be used when there is a wide variety in word length.
  • Icon button – Lower emphasis. Use when the action is less important and can be clearly communicated by icons.

Icons

Icons help clarify meaning, but should never be purely decorative.

For guidance on choosing and applying icons, see .

Usage

Multi-select segmented buttons can be used to filter. Don’t use more than five segments or let them wrap to a new line. Keep labels short and consistent. Don't mix icon-only labels with text labels. Set a maximum segment padding to maintain usability on large screens. Don’t let segmented buttons stretch across wide screens. Excessive padding reduces usability.
