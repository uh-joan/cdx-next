The Helix button component is built using selected styles from the Angular Material button framework. For implementation details, see the Code tab.

Options

Color and types

Buttons combine color themes and types to signal the importance of an action. Choose from these functional color themes:

  • Primary – Our default. Use for most actions.
  • Accent – Use sparingly for actions that need extra emphasis.
  • Negative – Use only for destructive or negative actions.
  • AI – Use for actions that trigger AI-powered tasks.
  • Invert – Use on dark backgrounds for contrast.

There are three button types to help communicate priority:

  • Flat (filled) – High emphasis. Use for the main action on a page.
  • Stroked (outlined) – Medium emphasis. Use for secondary actions.
  • Basic (text) – Low emphasis. Use when the action is optional or less important.

Density

Buttons are available in five size options, controlled by the density setting.

  • Density 0 is the default and most commonly used.
  • Use alternative densities to create a clear visual hierarchy—sparingly and with purpose.

Icons

Icons help clarify meaning, but should never be purely decorative.

  • Use a leading icon to reinforce the label’s intent.
  • Use a trailing icon to suggest interactivity, such as a dropdown or navigation.

For guidance on choosing and applying icons, see .

Buttons vs. links

Use buttons and links purposefully to support clarity and accessibility.

  • Use a button for actions that affect the current page—such as submitting a form, starting media playback, or closing a modal.
  • Use a link to navigate to a new page or to a different section within the current page (anchor navigation).

Avoid substituting one for the other. Buttons and links behave differently in browsers and are interpreted differently by assistive technologies. Using the correct element ensures a more inclusive experience for all users.

Usage

Use a single high-emphasis button per page to guide users clearly toward the primary action. Don't use multiple high-emphasis buttons, it can dilute focus and create confusion. Use icons when they enhance understanding and directly support the button’s purpose. Don't use icons that serve only as decoration or add unnecessary visual noise.

Icon button

Icon buttons enable users to perform small actions with a single tap.

Color

  • Primary – Our default. Use for most actions.
  • Invert – Use on dark backgrounds for contrast.
  • Negative – Use on the negative background only for destructive or negative actions.
  • Accent – Use sparingly for actions that need extra emphasis.

Density

Icon buttons are available in four size options, controlled by the density setting. The size affects the hover effect (and target area) but not the icon size.

  • Density 0 is the default and most commonly used.
  • Use alternative densities when you use icon buttons in a more restricted space.

Usage

A clear and concise tooltip should describe the action and appear on hover. Be cautious when using unfamiliar or ambiguous icons, as they may confuse users.

Floating action button (FAB)

Floating action buttons are used for the most common or important action on a screen, and they persist on screen when scrolling. They come in two sizes.

Color

  • Primary – Our default. Use for most actions.
  • Invert – Use on dark backgrounds for contrast.
  • Accent – Use sparingly for actions that need extra emphasis.
  • AI – Use for actions that trigger AI-powered tasks.

Usage

Use clear and simple icons such as add, message, or edit. Don't display multiple FABs on one screen and steer clear of confusing or vague icons for less common actions.
