Skeleton Loader provides a visual representation of content loading, giving users a seamless experience while waiting for data to load. The Helix skeleton loader is built with ngx-skeleton-loader. For implementation details, see the Code tab.

Options

Appearance

  • Line – The default. Renders like a line of text.
  • Circle – Great for avatar skeletons.
  • Custom content – No appearance is added. Great for custom content, such as SVG or internal components.

Animations

  • Progress – The default animation.
  • Progress dark – Recommended if your color scheme is dark.
  • Pulse
  • None – Disables the animation.

Installation

Using NgxSkeletonLoaderModule.forRoot()

You can also import the module in your app by calling NgxSkeletonLoaderModule.forRoot() when adding it, so it will be available across your Angular application.

Importing the module this way also allows you to globally configure the default values for the ngx-skeleton-loader components in your application, in case you need different default values for your app.

  • By default, every ngx-skeleton-loader component will use the theme coming from NgxSkeletonLoaderModule.forRoot() as the source of truth.
  • If there's any CSS attribute on the component locally which overrides the CSS spec, it combines both themes, but overrides global CSS attributes in favor of local ones.

Appearance

You can define which appearance to use in your skeleton loader by passing the option to your component via the [appearance] attribute.

  • '' – default: renders like a line.
  • line – renders like a line. This is the same behavior as passing an empty string.
  • circle – uses a circle as appearance. Great for avatar skeletons, for example.
  • custom-content – does NOT add any appearance. Great for custom content, such as SVG, internal components and such.

Animations

You can define which CSS animation to use - or none at all - in your skeleton loader by passing the option to your component via the [animation] attribute.

  • false (as boolean or string) – disables the animation.
  • progress – default: uses progress as animation.
  • progress-dark – uses progress-dark as animation. Recommended if your color scheme is dark.
  • pulse – uses pulse as animation.

Theming

You can define different styles for the skeleton loader by passing an object with the CSS styles - in dashed case - into the component via the [theme] attribute. The [theme] attribute accepts the same configuration as ngStyle, so you can use it just like the built-in directive.
