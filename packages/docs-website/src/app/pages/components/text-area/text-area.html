The Helix text area is built using selected styles from the Angular Material input framework and shares its styles and states with . For implementation details, see the Code tab.

Options

Styles

Both types of input fields use a container to offer a visual cue for interaction and deliver the same functionality.

  • Outlined – Less visual emphasis, helps to simplify the layout.
  • Filled – More distinct from other components (like buttons) and surrounding content.

States

The input component has integrated hover, focus and error states.

Usage

Keep the label text short, clear, and fully visible. Don't use labels that are too long, wrap onto multiple lines, or get truncated.
