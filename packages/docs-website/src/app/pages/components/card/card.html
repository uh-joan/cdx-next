The Helix card component is built using selected styles from the Angular Material card framework. For implementation details, see the Code tab.

Options

Use cards to group related content. They can contain anything—images, text, buttons, lists, charts or other components—and their layout and size adapt to the content inside.

Usage

Cards can be shown together in a grid, vertical list or carousel. Don’t use cards when spacing, headings, or dividers provide a simpler hierarchy.
