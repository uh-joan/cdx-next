The Helix badge component is built using selected styles from the Angular Material badge framework. For implementation details, see the Code tab.

Options

Color and size

Badges have two color themes and two sizes to signal the importance of an action.

Choose from two functional color themes:

  • Primary – Our default. Use for most actions.
  • Accent – Use sparingly for actions that need extra emphasis.

Usage

Use badges to show a count of items or notifications (e.g., number of filters applied). Ensure contrast and readability, especially against different backgrounds.
