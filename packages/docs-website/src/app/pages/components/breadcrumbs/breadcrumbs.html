The Helix breadcrumbs component is built using in order to provide a zero-configuration breadcrumb trail based on the state of the Angular router. The library is lightweight and customizable. cdx-breadcrumb is a simple wrapper component that establishes compliance with Clarivate brand and design standards.

Although xng-breadcrumb provides affordances for customizing the style of the breadcrumb trail, the HLX maintainers insist that no further stylistic changes are made.
