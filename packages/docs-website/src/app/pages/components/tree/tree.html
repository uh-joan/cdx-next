The Helix tree component is built using selected styles from the Angular Material tree framework. For implementation details, see the Code tab.

Options

Use trees with or without check boxes.

Usage

Create a clear hierarchy and use checkboxes where selection is needed. Don't clutter the tree list with unnecessary elements such as extra dividers. Maintain consistent vertical alignment across all hierarchical levels to ensure visual clarity and a cohesive layout.
