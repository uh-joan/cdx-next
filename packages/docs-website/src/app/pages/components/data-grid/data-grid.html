Use AG Grid for interactive tables with large data sets. Helix styles AG Grid with the Clarivate theme. For installation and theme setup, see the Code tab.

Options

Data grids follow the same guidance as :

  • Use clear, descriptive column headers that accurately reflect the data.
  • Include units of measurement in column headers if possible, not in individual cells.
  • Align text left and numeric values right to improve scannability.
  • Use consistent formatting for similar data types (dates, currencies, percentages).
  • Use row and column dividers sparingly to maintain visual clarity.
  • Ensure sufficient contrast and spacing for readability and accessibility.

Usage

Design tables to be clean and scannable, with a clear purpose and minimal, well-prioritized interactions. Don't overload tables with excessive controls or competing interactions that increase cognitive load and reduce readability.
