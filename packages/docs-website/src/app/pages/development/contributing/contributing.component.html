Contributing to HLX

HLX uses an innersource model to allow developers within the organization to contribute back to us.

  • New components
  • Component variants and updates
  • Bug fixes
  • Front-end services

How It Works

As a developer, you may be building out a component (or something else entirely) for an application that HLX does not currently offer. This happens because there are a lot of products with different needs. However, when you find that the work you are doing can be re-used by other teams, it's worth taking the time to talk to us about contributing it back to HLX. This allows HLX to consume the work you did and standardize it as part of our UI/UX offerings.
