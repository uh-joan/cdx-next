Overview

Density changes the size of components. Helix uses the same density scale as the Figma library: 0 is the default size, and each step down makes the component more compact.

Applying Density

Add a hlx-density-* class to a component, or to a container to apply it to every component inside. A class on an inner element overrides the one on its container, so hlx-density-0 restores the default size inside a compact area.

Each component only supports the levels defined for it in Figma. A level a component doesn't support leaves that component at the size it would otherwise have.
