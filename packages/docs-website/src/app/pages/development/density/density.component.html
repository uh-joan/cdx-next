Overview

Density is a system that allows you to apply size to components. Each level has a specific margin that is applied to one or all components.

Applying Density

To apply density to a component, you need to add the density class to the component. The density class is made up of two parts: density and the level. The level is always a negative number from 0 to -5. the smaller the number, the more dense the component will be.
