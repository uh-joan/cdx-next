Install Angular Material

Helix is based on , a set of themed components that conform to Google's spec. The best way to install Angular Material is to use the Angular CLI's installation schematic.

Note: Currently, Helix requires Angular Material Version 22.

Respond to the prompts:

  • Would you like to proceed? Yes
  • Choose a prebuilt theme name, or "custom" for a custom theme: Custom
  • Set up global Angular Material typography styles? No
  • Set up browser animations for Angular Material? Yes
