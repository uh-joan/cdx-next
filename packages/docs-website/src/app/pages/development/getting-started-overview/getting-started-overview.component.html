Product Vision

HLX aims to provide solutions that enable teams to efficiently deliver software experiences while following Clarivate branding guidelines and industry best practices. At its core, HLX covers all the components provided by Material both in code for engineering teams (for Angular environments), as well as via a Figma library for UX designers.

Why HLX?

A common variation of this question would be: "Why do I need to take the time to put the header and footer in my app using HLX if we already have these?"

Product cohesion, which includes the look and feel of interface, in addition to common user conventions positions Clarivate products with cohesive customer journeys which yield happier customers. Not to mention the ability to cross-sell and up-sell across products and segments. Please take a look at the design section for a deeper look at the .

The header and footer components have been designed to be turn-key solutions which can be integrated in a matter of hours regardless of the technology stack. The team that maintains HLX has collabrated with several teams to complete this work. Please to learn more about how we can help!

Accessibility

HLX Components are accessible to WCAG 2.1 AA standard. We test for critical or serious issues using a 3rd party accessibility toolkit.
