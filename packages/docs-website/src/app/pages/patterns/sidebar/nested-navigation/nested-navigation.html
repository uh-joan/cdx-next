When to use

When your product includes subcategories under main sections (nested navigation), a side navigation can serve as the primary navigation. Unlike horizontal navigation, which often relies on dropdowns to reveal subcategories, side navigation allows content to remain visible and well-structured without overwhelming the user.

That said, horizontal navigation can still be used to display essential elements—such as the product logo and user login icon—that are common across products in this location.

Dos and don'ts

Don’t hide frequently used or important options inside nested dropdown menus.

In the example, placing key items like “Searches and alerts,” “Search History,” and “Reports” nested under “My work” in a dropdown menu makes them harder to discover and access. If these options are essential to the user workflow, they should be surfaced in a more prominent and persistent location, like the side navigation panel.

Design considerations

  • Make the structure as shallow as possible, avoiding deeply nested levels — aim for maximum 2 levels of nesting.
  • Collapse child navigation by default.
  • Default the sidenav to an expanded state (when it serves as the primary navigation), since users will frequently switch between sections.
