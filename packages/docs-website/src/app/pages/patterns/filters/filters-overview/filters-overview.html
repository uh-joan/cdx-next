Filter types

Filter type Description
Text search Allows users to enter keywords to narrow results.
Category selection Uses dropdown lists, checkboxes, radio buttons or chips to segment content.
Boolean filter Allows users to narrow down data based on a simple true/false (yes/no) condition. It typically represents binary choices — for example, whether a sample is "approved" or "not approved," or whether a device is "active" or "inactive." In a user interface, a Boolean filter often appears as a toggle switch, a checkbox, or a pair of radio buttons.
Hierarchical filters Organize filtering options into multiple levels, where the choices at one level determine the available options at the next. They help users progressively narrow down data by selecting categories and subcategories in a structured way. In a user interface, hierarchical filters often appear as cascading dropdowns, expandable trees, or grouped categories. They are especially useful when datasets are large and complex, and when elements naturally fit into a parent-child relationship.
Numeric ranges Defines minimum and maximum limits (e.g., price, age, etc.).
Date filters Uses date pickers to define specific periods.
Advanced filters Combination of multiple criteria for greater precision.

Behavior and rules

  • Filters should update after user action.
  • Users should be able to easily clear filters.
  • Clearly indicate applied filters and allow their individual removal.

Best practices

  • If the filters are complex and numerous, it's recommended to use a for better usability, e.g., hierarchical filters.
  • Please avoid using both types of filters simultaneously.

Accessibility

  • Ensure filters are navigable via keyboard.
  • Provide clear labels for screen readers.
  • Include adequate contrast to improve readability.
