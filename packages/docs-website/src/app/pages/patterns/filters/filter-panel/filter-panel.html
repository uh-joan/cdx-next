It is a sidebar component that lets users apply filters while still viewing the results table.

When to use it

A filter panel is ideal when users need to refine large sets of information based on multiple criteria to find relevant results. We should consider using a filter panel when:

  • There are multiple filtering options across different categories.
  • Users need to apply several filters at once.
  • It’s important to view the results and filters simultaneously to maintain context.

Examples:

  • Results page
  • Dashboard

Components used

  • Text

Frequently used functionalities

  • Clear all / Select all: To clear the selected options.
  • Reset: When there’s a default configuration users might want to restore.
  • Search inside the list: When the list of items is quite long.
  • Cancel / Apply buttons: When filters cannot update results in real-time.
  • Alphabetical / Hierarchical views
  • Filter selected
  • Counts at the filter categories
  • Expand/Collapse button (sidebar)
  • Order by frequency

Best practices

  • The sidebar can be expanded or collapsed by default depending on the use case.
  • Group related filters together to enhance scannability.
  • Avoid having very long scrolling inside the bar; if the set of filters is very long, it is better to use the .
  • Provide a "Clear all" option to easily clear all filters.
  • Include a "Reset" button whenever there’s a default configuration that users may want to revert to.
  • Indicate active filters clearly so users always know how results are being narrowed down.
  • Remember, a well-designed filter panel helps users find what they are looking for faster, feel more in control, and have a smoother, more satisfying app experience.
