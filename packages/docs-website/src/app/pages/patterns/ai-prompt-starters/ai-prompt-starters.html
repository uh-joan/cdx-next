An assistant's first screen shouldn't be an empty box. Lead with a short greeting, a few suggested-prompt cards that seed the composer, and the composer itself. This is the empty state of the pattern, and follows the .

When to use it

The empty state of an assistant, before the first message — full-page or in a panel.

Do

  • Seed the composer (editable, focused) on card click; never auto-send.
  • Offer three to six specific, product-relevant starters as real buttons.
  • Reuse the conversation's composer.
  • Signal AI with the Helix treatment (avatar / gradient title), lightly.

Don't

  • Fire the question on card click — let the user edit first.
  • Use vague "ask me anything" starters.
  • Build the tiles as clickable divs.

Starters seed, they don't send

Clicking a starter fills the composer with an editable prompt and focuses it — keeping the user in control (the foundation's Assistive principle).

Example

Click a starter — it fills the composer (it doesn't send), ready to edit or ask.
