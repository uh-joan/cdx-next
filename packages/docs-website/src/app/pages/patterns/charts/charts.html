Charts should look like the rest of the product: the same palette, type and muted axes. Helix ships that as the Highcharts styled-mode theme in @cdx/theme-highcharts, so you render in styledMode and let the theme supply colour and styling instead of setting it per chart. See the component for the base wiring.

When to use it

Visualising quantitative data — trends, comparisons, distributions. A single number or short comparison is better as a stat tile, a table or inline text.

Do

  • Render in styledMode with the Helix Highcharts theme.
  • Take the series palette from the theme; never hardcode colours (import HLX_HIGHCHARTS_THEME_COLORS for D3 / custom SVG).
  • Title the chart and both axes; enable accessibility; offer the data as a table.
  • Use a responsive container and let the chart reflow.

Don't

  • Hardcode a colour array in options or a constants file.
  • Encode meaning (good / bad, categories) in colour alone — pair it with a label, pattern or shape.
  • Pin a pixel width.
  • Reach for a pie chart with many slices.
