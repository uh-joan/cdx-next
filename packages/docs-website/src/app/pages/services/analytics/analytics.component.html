Overview

ngx-analytics package provides a seamless way to integrate user tracking within a Clarivate app environment.

It uses Snowplow browser-tracker under the hood. You can read more about it through this . ngx-analytics reads user's preferences if OneTrustModule of branding package is present. If this module is available events only get tracked when user accept cookie preferences.

Installation

Install Analytics Package Add analyticsModule in your AppModule and AnalyticsService in the providers array of the consuming module. Where settings are defined following AnalyticsSettings interface: Schema for context is defined following AnalyticsContextSchema interface. You can find information about Clarivate IGLU schema on the wiki page

Usage

Add analyticsService to the component constructor method. Track user events with trackEvent method. To see more details about Snowplow Structured event click here Track user page views using trackPageView.

Context

A context Schema can be provided on AnalyticsModule.forRoot() declaration. By default CLARIVATE_IGLU_SCHEMA is provided but a custom one can be difined. You can read here more about how to create a Self-describing JSON

AnalyticsService also provides resetContext and updateContextData which allow to override defined context and update specific attributes as shown on the next example.

Context can be provided also on trackPageView and trackEvent methods.
