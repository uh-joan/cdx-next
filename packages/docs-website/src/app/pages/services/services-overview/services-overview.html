Services

The Experience Engineering team provides the following services to Clarivate teams:
  • Provide a walk through and overview of the HLX and its capabilities.
  • Common workflows with the Angular CLI such as setting local development proxies for remote API calls.
  • General onboarding and getting started guidance for using HLX properly.
  • Providing designers with a Sketch library that reflects both HLX and Material live components.
  • Custom internal services.
