Density principles

Density in Helix is guided by three core principles:

  • Default-first – Density 0 is the standard for most interfaces. It offers the best balance of space, clarity, and accessibility.
  • Consistent – Never mix different density levels within a single view. Components presented together (e.g. a button group) should always share the same setting.
  • Context-aware – Use compact densities only where screen space is limited or dense information is presented (e.g. dashboards, admin tools, data tables).

Component scaling

Density in Helix is applied through Google Material 3’s Component Scaling, which adjusts internal spacing - typically by reducing vertical padding or height in 4px increments per level.

Density is only supported on certain components and within clearly defined limits to preserve usability and legibility.
