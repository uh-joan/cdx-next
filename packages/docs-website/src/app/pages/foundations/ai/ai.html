AI principles

AI in Helix follows a set of core principles to ensure that AI-powered features remain clear, trustworthy, and usable.

  • Transparent – Users should always understand when content is generated by AI. Clear visual indicators and disclaimers help distinguish AI output from system or human-generated content.
  • Assistive – AI supports user workflows - it does not replace user decision-making. AI features should help users move faster, explore information, and make informed choices.
  • Trustworthy – AI interactions should feel predictable and understandable. Clear states, feedback, and explanations help build confidence in AI-generated results.

Gradient

Helix uses a distinctive blue-to-purple gradient from the Clarivate brand guidelines to visually identify AI-powered functionality. The gradient creates a strong visual signal that differentiates AI features from standard UI elements while maintaining alignment with the broader brand system.

Specification

To ensure consistency with the Clarivate identity, gradients must follow the defined brand rules. They are applied at a 30-degree angle, aligned to the composition grid, with gradient start and end points positioned at the top and bottom of the element or layout.

Usage

The gradient is used in:

  • AI buttons
  • AI avatars
  • Titles on AI-focussed pages
  • Banners for AI features

Use the gradient consistently and sparingly to reinforce recognition without creating visual noise.

Button

AI functionality in Helix is supported through dedicated AI-themed versions of existing button components. These variants visually distinguish AI-powered actions while maintaining the same structure, behaviour, and accessibility standards as standard buttons.

The standard Button component includes AI-themed versions. The Floating Action Button (FAB) also includes an AI theme, allowing prominent AI actions to be clearly identified.

AI buttons are visually distinguished using the blue-to-purple gradient, signalling that the action involves AI-generated output. Use AI-themed buttons for actions that generate, transform, or analyse content using AI.

Avatar

The AI Avatar is used to identify AI-generated responses and distinguish them from user, system, or application content. It provides a consistent visual cue that helps users quickly recognise when they are interacting with AI.

Use the AI Avatar whenever displaying responses, messages, or content generated by an AI tool - particularly in conversational interfaces and assistant experiences. To maintain consistency with the Helix AI identity:

  • Use the gradient avatar wherever possible to align with the Clarivate brand.
  • If the gradient is not suitable for a specific interface, use the dark theme.

Loading state

When AI is generating a response, the sparkles icon within the avatar should animate to indicate that processing is in progress.

This animation provides immediate feedback that the system is working and helps reassure users during response generation. The animation should be subtle, consistent, and used across all AI experiences that display the AI Avatar.

Consistent use of the AI Avatar and its loading state helps build recognition, reinforces transparency, and creates a more trustworthy AI experience.

Streaming status text

During longer operations, Helix uses animated streaming text to communicate what the AI is doing in real time. This text provides transparency by describing intermediate steps, such as:

  • Searching sources
  • Analysing information
  • Generating results
  • Comparing content

Streaming text helps users understand progress and reduces uncertainty during longer generation times. Use streaming status text when:

  • Generation takes more than a few seconds
  • Multiple processing steps are involved
  • The system is analysing large or complex data sets

Avoid overly technical language - status messages should remain clear and human-readable.

Disclaimer

AI-generated content must always be clearly identified to support transparency and user trust. Use disclaimers to inform users when content has been created or modified using AI. Placement depends on the context:

  • Full AI-generated pages – Place the disclaimer in the footer.
  • Inline AI responses – Display the disclaimer near the generated content.

Disclaimers should remain visible, concise, and consistently styled.

Layout

AI functionality can appear in different interface contexts depending on the task and workflow. Helix supports several standard AI layout patterns to ensure consistency across products.

Inline AI

Inline AI appears directly within existing content areas, supporting users without interrupting their workflow. Use inline layouts when:

  • Enhancing existing content
  • Providing contextual suggestions
  • Supporting quick actions

Side panel or chat layout

Side panel layouts display AI interactions alongside primary content. Use this layout when:

  • Supporting conversational workflows
  • Allowing iterative refinement
  • Maintaining visibility of source content

Modal or overlay

Modal layouts present AI functionality as a temporary, focused interaction. Use this layout when:

  • Running short AI tasks
  • Displaying focused results
  • Supporting review before committing changes

Full-page AI workspace

Full-page layouts are used when AI interaction becomes the primary workflow. Use this layout when:

  • AI is central to the experience
  • Large outputs need space to be reviewed
  • Multi-step interactions are required
