Elevation principles

Helix applies elevation with restraint and purpose. Shadows should clarify structure—not decorate the interface. Our approach follows three key principles:

  • Purposeful – Use elevation to reinforce meaning, such as highlighting active elements or layering modal content.
  • Minimal – Most surfaces remain flat. Elevation is reserved for components that require visual distinction.
  • Consistent – Only use the defined Helix elevation levels. Custom or excessive shadows can disrupt clarity and visual rhythm.

Elevation levels

Helix uses four elevation levels, based on the Google Material 3 Elevation. All shadows are system-defined to maintain visual consistency and accessibility across themes.

Usage guidance

Helix intentionally limits elevation to a small set of values. This constraint encourages thoughtful, consistent application across the UI.

  • Stick to a single elevation level per element or component group.
  • Avoid layering multiple elevation levels within the same layout area.
  • Use higher elevation sparingly, and only when necessary to support interaction or focus.
