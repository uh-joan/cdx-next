Responsive web design, also called RWD design, describes a modern web design approach that allows websites and pages to render (or display) on all devices and screen sizes by automatically adapting to the screen, whether it's a desktop, laptop, tablet, or smartphone.

How It Works

Responsive web design works through Cascading Style Sheets (CSS), using various settings to serve different style properties depending on the screen size, orientation, resolution, color capability, and other characteristics of the user's device. A few examples of CSS properties related to responsive web design include the viewport and media queries.

The grid system is a way of building layouts using a grid containing several columns. When designing in any UI design tool (Sketch, Figma, Adobe XD) you can create a set of columns in which to organize your UI layout. Everything has a grid system applied in some form, from components to the page layout. A grid system also helps with responsive design, as it is easier to make decisions regarding how the page layout will change based on the viewport size.

Columns

  • Typically, a designer will choose between 2 and 12 columns per layout
  • The smaller the screen width, the less columns should be used
  • A component (or any layer) can spread across multiple columns
  • There can be gaps between each column if whitespace is of a concern

Column Gaps

Columns can have gaps (also known as gutters) that separate each column. This purpose is primarily for introducing whitespace between columns for page layouts. If whitespace is built into the component directly, then gap spacing is not needed between your columns. This is up to the designer to decide. Its primary purpose is for creating layouts and ideating on responsive design. HLX does not offer a development solution, and instead leaves it up to each team to decide on how they want to handle layouts and responsiveness from a development perspective.

You can target multiple screen sizes by adjusting your layout at various breakpoints. While mobile isn't the target for most enterprise-level or desktop applications, it's good to know your options when necessary.
