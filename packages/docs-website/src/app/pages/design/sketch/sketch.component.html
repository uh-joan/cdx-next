Sketch is a UI design tool at Clarivate.

Step 1

First, you need to install Sketch on your computer. You can visit their website and download the Mac OS app.

Step 2

  • Request access to the Clarivate Sketch account
  • For access, please contact KD directly at kd.arneja@clarivate.com
  • Log-in to the Clarivate account

Step 3

  • Create or edit an existing project in Sketch
  • Link the UI library to your project

Each symbol is named and organized based on its purpose within the design system. Following along with the concept of , symbols are broken down into the smallest piece possible for use by designers.

The library is organized into 3 primary sections:

Tokens

A token serves as the most fundamental building block in which to build UI's with. A token is an individual element that by itself cannot be interacted with by users. Tokens include colors, icons, spacing, shadows, typography, among others. As design files are a static medium, the tokens used within Sketch are limited to what can be added to the UI easily. For developers, tokens are typically broken down further than what Sketch is currently capable of.

Elements

Elements are a relatively simple groups of design layers functioning together as a unit, such as an input. By itself, it does not have much use. But by including it with a series of other elements, can make up a portion of the interface. For instance, a form element by itself without context (no button, no header, no form) is not very useful. However, by combining it with other inputs, adding a submit button and a few labels, and now you have a complete series of elements that make up a form.

Components

Components are more complex UI layers consisting of multiple elements and tokens combined. In Sketch it is a fully responsive symbol that represents a specific purpose. For instance, the card component is made up of a background, drop-shadow, typography, image, and buttons. The purpose of a card is to display a small portion of a larger piece of content. It is a representation of a more complex set of interactions that the card is typically linked to.

If your team doesn't use Abstract or Invision, you can access the library through as part of the Sketch for Teams (Enterprise) account. You can either point to the library within the project, or open up a component file and copy over the components into your own project.

There are 2 different types of library files to choose from.

Linked Library

A linked library file HLX.sketch is the main component library. This includes all the components that are built either by Clarivate, or supported through Material Design. This is what you will most likely be using. You shouldn't need to open the main library file, only link to it in your project.

Un-linked Flat File

An unlinked file just means it’s not a library file. A flat file refers to each component (or symbol) being entirely independent from the rest of the symbols within the system. This is so a designer may copy and paste any component they wish into their own project without any complications. If you copy linked library components into your file it will result in additional design artifacts coming along that you don’t need. It’s not a bug in Sketch, just how the system works.

For example, if you need a single icon but not the entire 1800+ icon set, just open the flat file for icons. A flat file is also more condensed, so a slower computer won’t struggle opening it, compared to opening the more complex library file. Flat files are also best if you wish to change the default color scheme, as theme overrides in the main Sketch library file are not supported.
