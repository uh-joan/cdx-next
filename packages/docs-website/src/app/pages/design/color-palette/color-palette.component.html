Clarivate's colors used in interface design follow a set of standards. How color is applied, where, and why are important within the designs.

  • The brand color is the primary color for actionable elements
  • Neutrals are used for background elements
  • Semantic colors are used for specific meaning
  • For each color there is a dark and light variant
  • Material Design uses a color scale ranging from light to dark

Primary Colors



ABOUT

The primary color is used to call attention to the most important user actions in the UI. As screen real estate of the primary is typically related to user actions, these component interactions remain visually obvious to your users.


EXAMPLES

Buttons, CTA’s, Links, FAB, Icons, etc.


Accent Colors



ABOUT

The secondary accent color is a complementary color to the primary. It is meant to call attention to areas of importance that are not actionable, but instead meant to highlight the static parts of the interface that require a user's attention (that are not semantic).


EXAMPLES

A toolbar, component header, secondary attention

Neutral Colors



ABOUT

The neutral colors are used for background layering of components and interface elements. Most of your screen real estate should be neutral colors so as to not distract the user. They must not diminish or overtake the primary, accent, or semantic colors within the UI.


EXAMPLES

Page backgrounds, component backgrounds, visual separation of elements, elevation (drop shadows)

Semantic Colors



ABOUT

The semantic colors are used to communicate specific meanings within the state of the UI. Within a component, a semantic color is referred to as a variant from the original state.


EXAMPLES

Buttons, component variants, etc.

Color values are represented as design tokens for developers to access when building applications. Designers typically will get the color values directly from the Sketch UI Library file.
