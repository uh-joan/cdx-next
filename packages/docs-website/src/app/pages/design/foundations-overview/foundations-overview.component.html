Clarivate has their own set of product guidelines built on top of the Material platform. They are a set of rules explaining how your brand works in relation to product UI design. Internal guidelines allow us to have more refined control over the interface and help define the qualities of our products within the interfaces, components, and interactions.

Google has their own set of guidelines for Material Design.

The foundational elements are what make up a majority of the interface. They control the layout, responsiveness, colors, font, imagery, etc. Most elements for designers can be found directly in the Sketch UI library.
