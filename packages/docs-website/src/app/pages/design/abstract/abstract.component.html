Abstract is a version control system for Sketch. Here you can learn how to use Abstract and build Sketch files directly within their application, and access Clarivate's UI component library.

Step 1

First, you need to install Abstract on your computer. You can visit their website and download the Mac OS app.

Step 2

  • Request access to the Clarivate Abstract account
  • For access, please contact KD directly @ kd.arneja@clarivate.com
  • Log-in to the Clarivate account

Step 3

  • Create or edit an existing project in Abstract
  • Link the UI library HLX Baseline > HLX to your project under the "Add File" menu
  • Log-in to the Clarivate account

Step 4

  • Open the components/symbols window and the linked library should be now visible
  • Drag & drop components as needed

The most productive way for a team to handle versioning of project-related sketch files is to separate the updates into different feature-based branches. This means that a working copy (called a branch) of project files might include updates, new features, or design requests. A branch might also be for bug fixes, such as updating the layout or responsive design of a symbol. Once a working branch is accepted, it can merge back into the main branch of the project for immediate consumption by any design team.

The primary purpose behind versioning is to prevent accidental losses of work when multiple designers are involved in the process.

If you wish to export a file from a project, you can do so by right-clicking on the file in Abstract directly and choosing "export".

For detailed information on using Abstract, you can watch videos on their YouTube channel.
