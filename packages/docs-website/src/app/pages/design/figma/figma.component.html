Figma is the primary design tool for interface design. It allows designers to create fully interactive experiences for product communication and developer hand-off. It can be accessed within the browser or through the desktop application. It is designed for both Windows and Mac.

Designers who want access to the Figma library should contact Naila Haider or KD Arneja.

When creating a new project file, go under the assets tab, located within the left panel and click on the bookmark library icon to show the library panel.

The HLX UI library should appear as an option within the popover. Toggle the library option to 'on'.

For quick access to the library once imported, you can press "Shift + I" and select the HLX-Library from the dropdown menu.
