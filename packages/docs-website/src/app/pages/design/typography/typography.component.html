Typography is used to create clear hierarchies, useful organization, and purposeful alignments that guide users through the product and experience. It is the core structure of any well designed interface. We use the scaling system built into the Material platform to create this structure.

The default weights for each style can be overridden if you feel that the weight is too strong or too light. It depends on the context of the UI and page content. Make sure to communicate this with the developer, else they will use the defaults.

You don't need to override the font size directly. Instead, you can just reference another type name that controls font styles. This creates consistency of type hierarchy.

Headings

Pick the appropriate sized heading for your interfaces. You are not confined to using them in numerical order, but instead look to build a proper visual hierarchy of your type. Headlines do not necessary need to be semantically connected to html tags h1, h2, etc.

For example: A page headline can be set to Display 1-4 in Angular based on the UI design.
