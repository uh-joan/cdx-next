# Adopt VSCode as preferred editor

- Status: accepted
- Date: 2022-02-04

## Context and Problem Statement

We can reduce onboarding and cycle time by providing an "out of the box"
developer experience in a preferred editor (IDE).

## Decision Outcome

Adopt [VSCode](https://code.visualstudio.com/) 🔥

See minimal setup notes in the [Contribution Guide](../CONTRIBUTING.md).

### Positive Consequences

- all shared settings work "out of the box"
- reduced onboarding time
- minimized tool setup time

### Negative Consequences

- some might have an alternate IDE preference (if so, they can contribute its
  configuration 👍)
